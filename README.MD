# Komodo configuration
My [Komodo](https://komo.do) 🦎 configuration for my homelab. 

## Structure
I follow the excellent suggestions in the blog from [FoxxMD](https://blog.foxxmd.dev/posts/migrating-to-komodo/), so my structure looks something like this;

```
-- This README.md
|-- servers
     |-- prime
          |-- stacks
          |    |-- komodo
          |    |-- media
          |    |-- tools
          |    |-- ...
          |-- syncs
```

I've included additional README files for stacks that need some additional configuration (like I needed for Plex). See the folders for more information.
